# Repository instructions

## Knowledge-first policy
For important planning, analysis, research and decisions in any domain/project, first evaluate whether stored knowledge is useful. If the `knowledge` MCP is available, search it, inspect relevant notes and trace important claims to their source. When recency matters, compare with current authoritative web information. Separate sourced facts, author claims, assumptions and recommendations. Do not claim that MCP tools ran if unavailable.

Follow [docs/knowledge-use-policy.md](docs/knowledge-use-policy.md). This is repository-scoped guidance, not a ChatGPT-global setting. Do not modify secret files or invoke knowledge write tools without a task that requires it.
