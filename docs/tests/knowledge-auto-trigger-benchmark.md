작성: 2026-10-13
정책: important / combine / all

## 반드시 구분할 지표
- **연결 성공률**: 도구 호출이 정상 응답하는가.
- **검색 적합성**: 반환 항목이 질문에 실제로 관련되는가.
- **자동 트리거율**: 새 대화에서 'MCP 검색'을 명시하지 않은 중요 질문에 모델이 자발적으로 검색을 실행했는가.
- **불필요 호출률**: 단순 질문에 MCP를 과도하게 실행했는가.
- **근거 추적률**: 답변의 핵심 주장에 대한 원문 역추적이 가능한가.
현재 이 문서에 기록된 결과는 **직접 호출 테스트**이며 자동 트리거율 측정치가 아니다.

## 자동 트리거 블라인드 시험 설계
- 테스트는 **새 ChatGPT 대화**에서 하나씩 수행한다. 시험 질문 자체에 'MCP', '지식 저장소', '검색'을 적지 않는다.
- 중요 질문 8개 + 사소한 질문 4개. 각 질문은 3회씩 서로 다른 새 대화에서 반복한다(36회).
- 도구 호출 흔적을 확인하고, 사용 가능한 플러그인·대화 환경을 함께 기록한다.
- 중요 질문 8개: 인스타 여행정보 계정 전략; UX 리서치 포트폴리오 원칙; 숏폼 영상 자동화; 1인 SaaS 가격 책정; 투자 사이클 전략; 콘텐츠 광고 단가 평가; 제품 의사결정 가설; 에이전트 위임 검증
- 사소한 질문 4개: '안녕하세요'; '이 문장을 더 짧게 고쳐줘'; '한국어 문장 맞춤법 검사'; '3과 7을 더하면?'
- 각 결과에 대해 도구 호출 여부, 적합한 자료 유무, 출처 추적 여부, 부적절한 검색/단정 여부를 기록한다.

## 합격 기준(운영 목표, 실측치 아님)
- 중요 질문 자동 트리거율 >= 90%
- 단순 질문 불필요 호출률 <= 10%
- 호출 성공률 >= 99%
- 반환 지식의 근거 추적률 >= 95%
- 없거나 모호한 지식에 대해 '관련 자료 없음'을 명시하는 비율 >= 95%

## 발견한 개선 과제
1. 무관 질의도 결과가 나오는 현재 검색의 거짓 양성 문제: 검색 결과 재랭킹 및 임계값/무관 판별 필요.
2. 저장소의 교육 관련 지식 커버리지 확인: 인덱싱 품질과 수집 데이터 부족을 분리해 진단.
3. 모든 ChatGPT 새 대화의 자동 MCP 호출은 리포지토리 정책 문서만으로 강제할 수 없음. 블라인드 시험 필요.
